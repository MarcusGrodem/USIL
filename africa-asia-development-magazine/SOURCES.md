# Sources and Research Register

This file contains sources, datasets, frameworks, cases and organisations mentioned in the project conversation. It is a working register, not yet a finished bibliography.

The descriptions below record how each source entered the project. Where full bibliographic information was not provided in the chat, the item is marked **Citation details still needed**.

## Source rules

- Do not cite this file as evidence by itself.
- Open and verify each source before using it in the final magazine.
- Record the exact claim, table, page or indicator used.
- Distinguish peer-reviewed research, working papers, institutional reports and background websites.
- Add publication date, author, title, publisher, URL and access date in the required citation style.
- Do not use placeholder figures from the rough PDF.
