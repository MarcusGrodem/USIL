# Tools

## make_magazine_draft.py

Python/ReportLab script used to generate the legacy 45-page rough storyboard.

The script is useful for:

- reproducing the existing legacy PDF;
- reviewing page structure;
- extracting build-note and infographic ideas;
- recovering ideas for the current approximately 25-page plan before the final Canva build.

It is not the planned final production environment. The current preference is Canva for the magazine and Genially for interactive content.

The script's colours predate the final palette guide, and its 45-page pagination is no longer the production target.
