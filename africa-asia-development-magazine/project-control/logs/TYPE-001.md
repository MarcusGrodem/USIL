- **Decisions and limitations:**
    - **Recommendation, not lock.** The project lead asked for three options and a visual tester, so this task deliberately stops short of locking a family. `design/TYPOGRAPHY_DECISION.md` is not written yet; it will be created on selection.
    - **Open-licence requirement.** Only SIL OFL candidates were included so that the magazine can be printed, projected, PDF-embedded, and classroom-distributed without a licensing audit.
    - **Hierarchy expressed in points (page level) and viewBox units (figure level).** The two scales are kept separate so figure geometry does not drift when a different typeface is selected.
    - **Tabular lining numerals are a hard requirement.** All three candidates satisfy it; the fallback stack repeats the directive so the magazine still reads correctly when the chosen family fails to load.
    - **No figure change in this task.** No current SVG or spec is edited; the Aptos string stays in all four production SVGs until the typography decision is recorded.
    - **Visual tester is self-contained.** `fonts.css` holds all six woff2 bundles as base64 data: URIs; the PDF re-renders without network access and without the fonts/ directory.
    - **Known rendering note.** Chrome headless embeds the three candidate families as Type 3 subset fonts (vector outlines per glyph). This is visually identical to TrueType embedding, slightly larger in file size, and does not affect reading quality. A future PDF built with LaTeX/xelatex (or Chrome stable in a different mode) may produce TrueType subsets instead; neither path changes the design decision.
