# Roadmap to the Final Report

The Roadmap Controller uses `REPORT_CHECKLIST.md` for the simple view and this file for ordering the work.

## Phase 0 — Control the project

**State: DONE**

- Lock countries, years, theories, and section ownership.
- Establish the controller, checklist, status board, prompts, logs, APA rules, and graph rules.

Completion gate: a new agent can see what is done, missing, active, and blocked without earlier chat history.

- Create map/image credit registers.

Completion gate: every Ghana/South Korea headline claim traces to an exact value or passage and a complete APA reference.

**State: DONE for bounded country evidence; later publication verification remains visible**

## Phase 6 — Write and assemble the magazine

**State: MISSING**

- Write final copy only from approved evidence.

- Add citations, captions, credits, and comparison limitations.

Completion gate: each page passes the per-page checklist and no placeholder/build note remains.

## Phase 7 — Build interactions, AI activity, game, and presentation

**State: MISSING**

- Select and build two useful interactions with static alternatives.
- Complete and test the research-gated Development Evidence Lab from approved evidence.
- Define and prototype the companion game without weakening the project's evidence standards.
- Create the presentation, shared cue sheet, and question preparation.
- Rehearse every member.

Completion gate: links work, offline versions exist, the AI activity and game pass their evidence/use tests, and any member can present the argument.

## Phase 8 — Audit and submit

**State: MISSING**

- Run separate evidence/APA, graph/data, editorial/cultural, accessibility, rights, and export checks.
- Place approved deliverables in `final/`.

Completion gate: every final-quality item in `REPORT_CHECKLIST.md` is checked.

## Critical path

```text
APA and evidence rules
  -> six-country + thematic research
  -> theory testing
  -> final figures
  -> page writing and assembly
  -> interactions and presentation
  -> final audits and delivery
```

Country research, thematic research, APA cleanup, and chart-system prototyping can run in parallel. Final prose must not outrun verified evidence.
