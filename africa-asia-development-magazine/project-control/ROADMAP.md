# Roadmap to the Final Report

The Roadmap Controller uses `REPORT_CHECKLIST.md` for the simple view and this file for ordering the work.

## Phase 0 — Control the project

**State: DONE**

- Lock countries, years, theories, and section ownership.
- Establish the controller, checklist, status board, prompts, logs, APA rules, and graph rules.

Completion gate: a new agent can see what is done, missing, active, and blocked without earlier chat history.

## Phase 1 — Fix evidence and citation foundations

**State: IN PROGRESS**

- Create source and claim registries.
- Convert verified sources into APA 7.
- Define indicators, units, proxy rules, and missing-data rules.
- Create the chart-ready master data structure.
- Create map/image credit registers.

Completion gate: every Ghana/South Korea headline claim traces to an exact value or passage and a complete APA reference.

## Phase 2 — Complete all six countries

**State: IN PROGRESS**

- Finish Ghana and South Korea gaps.
- Research Botswana, Mauritius, Malaysia, and the Philippines with the identical template.
- Compare definitions across all six cases.

Completion gate: every required country item in the checklist is done or explicitly unavailable with a documented reason.

## Phase 3 — Complete historical, economic, and cultural research

**State: READY**

- Produce page-mapped evidence for structural transformation, colonial rule, infrastructure, borders, exports, industrial policy, Hofstede, and trust.
- Add counterevidence and exceptions.

Completion gate: every planned evidence page has approved claims, APA citations, limitations, and a visual candidate.

## Phase 4 — Test the three theories

**State: BLOCKED by Phases 2–3**

- State mechanisms and predictions.
- Test each theory across cases.
- Record support, counterexamples, alternatives, limitations, and revisions.

Completion gate: the theory matrix is evidence-backed and does not present original hypotheses as established academic theories.

## Phase 5 — Build comparable figures

**State: IN PROGRESS at prototype level**

- Approve a reusable comparison system.
- Build matched dashboards, trajectories, small multiples, timelines, maps, and theory visuals.
- Save underlying data and APA notes.

Completion gate: all graph items in the report checklist pass independent numeric and visual-comparability checks.

## Phase 6 — Write and assemble the magazine

**State: MISSING**

- Write final copy only from approved evidence.
- Assemble all 45 pages using the final design system.
- Add citations, captions, credits, and comparison limitations.

Completion gate: each page passes the per-page checklist and no placeholder/build note remains.

## Phase 7 — Build interactions and presentation

**State: MISSING**

- Select and build two useful interactions with static alternatives.
- Create the presentation, shared cue sheet, and question preparation.
- Rehearse every member.

Completion gate: links work, offline versions exist, and any member can present the argument.

## Phase 8 — Audit and submit

**State: MISSING**

- Run separate evidence/APA, graph/data, editorial/cultural, accessibility, rights, and export checks.
- Place approved deliverables in `final/`.

Completion gate: every final-quality item in `REPORT_CHECKLIST.md` is checked.

## Critical path

```text
APA and evidence rules
  -> six-country + thematic research
  -> theory testing
  -> final figures
  -> page writing and assembly
  -> interactions and presentation
  -> final audits and delivery
```

Country research, thematic research, APA cleanup, and chart-system prototyping can run in parallel. Final prose must not outrun verified evidence.
