# AI Quiz Acceptance Checklist

The quiz is ready for classroom use only when every required item below passes.

## Research gate

- [ ] The completed pack uses only approved project evidence.
- [ ] Every substantive claim and statistic has a matching source/claim ID and APA 7 in-text citation.
- [ ] Definitions, units, years, and actual proxy years match the frozen research.
- [ ] The pack includes the matched Ghana–South Korea comparison.
- [ ] The pack includes meaningful variation within both regions.
- [ ] At least one African counterexample and one Asian within-region contrast challenge a simple regional story.
- [ ] Cultural explanations are tested against historical, institutional, policy, and economic alternatives.
- [ ] Every major comparison states what it cannot prove.
- [ ] Original group theories are labelled as theories rather than established evidence.
- [ ] Final search of the completed release copies for `{{` and `}}` returns zero results.

## Learning-design gate

- [ ] The activity has one or two clear learning goals.
- [ ] Five to eight concepts are explained in simple English.
- [ ] The activity uses the five project-specific investigation rounds.
- [ ] The rounds move from an initial hypothesis to a revised evidence-based verdict.
- [ ] Every Evidence Card and task is answerable from the approved source pack.
- [ ] The AI runs one round at a time and waits for the response.
- [ ] Partial and incorrect answers receive progressive clues before a model answer.
- [ ] Students must explain reasoning, not only name an answer.
- [ ] The team uses the CEAL framework: Claim, Evidence, Alternative, Limit.
- [ ] The final evaluation uses the stated weighted calculation and project-specific result bands.

## Cultural and editorial gate

- [ ] No question treats Africa, Asia, or any country as culturally uniform.
- [ ] No prompt wording implies that culture alone caused the observed outcome.
- [ ] Multiple cultural dimensions appear only where evidence supports them.
- [ ] Stereotype-based answers receive a respectful evidence-testing response.
- [ ] Examples explain what they demonstrate, challenge, and cannot establish.
- [ ] Language is concise and understandable to undergraduate students.

## Test conversations

Run and save at least these six short tests:

1. A strong evidence-based answer.
2. A partly correct answer missing a limitation.
3. A confident but unsupported causal answer.
4. A stereotype-based regional generalisation.
5. An answer using the wrong year, unit, or proxy.
6. A group that asks to stop before Round 5.

For each test, verify that the AI follows the intended hint sequence, does not invent evidence, and scores only what occurred in the conversation.

## Presentation readiness

- [ ] The chosen AI platform has been tested with the full prompt and source pack.
- [ ] A presenter knows how to start, pause, restart, and end the activity.
- [ ] A classroom-screen readability check has passed.
- [ ] Timing fits the presentation slot.
- [ ] A static/offline version of the questions, hints, evidence notes, and rubric exists.
- [ ] No student names or personal data are required or retained.
- [ ] A second person has checked factual accuracy and scoring behaviour.
