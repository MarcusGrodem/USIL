# Development Evidence Lab

## Purpose

This folder prepares the project's original classroom AI activity for the project topic:

> **Economic development in Africa: Why this region couldn't grow like the Asia region — cultural analysis.**

The AI runs a five-round **Development Evidence Lab**. A student group creates an initial hypothesis, examines matched evidence, tests a cultural mechanism, confronts counterexamples, and delivers a revised verdict. The activity uses the project's own **CEAL test: Claim, Evidence, Alternative, Limit**.

The supplied prompt from another class was used only as inspiration for the broad idea of a conversational AI teacher. Its Value Stream Mapping content, section sequence, six-question ladder, star ratings, and evaluation identity are not part of this project format.

The teacher-assigned wording is treated as a question to investigate, not as a conclusion. The quiz must not imply that Africa or Asia is uniform, that culture is fixed, or that culture alone caused different development outcomes.

## How to finish it after the research

1. Create one completed research pack from approved claims, figures, counterexamples, limitations, and APA 7 references.
2. Paste that pack into the marked source section of the master prompt, or attach it with the prompt on a platform that supports files.
3. Work from copies of the research-pack template and acceptance checklist. Replace every `{{PLACEHOLDER}}` in those completed copies; a final search of the release copies must return zero results.
4. Test the prompt with strong, partial, incorrect, and stereotype-based answers.
5. Verify that it runs one investigation round at a time and does not reveal model answers too early.
6. Run the acceptance checklist and obtain a second-person evidence review.

## Presentation use

One group member can paste the completed prompt into the chosen AI tool and share the screen. The class or presenting group discusses each case before responding. A non-interactive backup should preserve the same five rounds, Evidence Cards, nudges, CEAL framework, and scoring rubric in case the AI tool or internet connection is unavailable.

## Scope boundary

This is a learning and presentation method, not an evidence source. The AI may explain and evaluate only from the supplied, approved research pack. It must distinguish:

- sourced evidence;
- interpretation supported by that evidence;
- the group's original theories;
- uncertainty, missing data, and alternative explanations.
